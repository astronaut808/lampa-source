# Архитектура

```text
Hisense VIDAA ──HTTP/LAN──> Astronaut Lampa (nginx:8080)
      │                              │
      │                              ├── CUB API
      │                              ├── внешние плагины
      │                              └── источники контента
      │
      └── временно: https://vidaahub.com ──> VidaaEdge в LAN
```

Lampa — статический frontend. Контейнер не содержит CUB proxy, базы данных или пользовательских секретов.

VidaaEdge разворачивается отдельно и используется для создания записи PWA в меню VIDAA. DNS-подмена `vidaahub.com` не относится к работе CUB и не должна применяться ко всей сети без необходимости.

Custom-код изолирован в `src/custom`. Upstream-модули аккаунта и загрузки плагинов не изменяются.
