# Проверка CUB

CUB-клиент в форке не изменён. Собственный origin имеет отдельный localStorage, поэтому первый вход нужно выполнить заново.

## Сценарии

- [ ] Открывается экран входа.
- [ ] Вход завершается успешно.
- [ ] Отображается профиль.
- [ ] Загружается избранное.
- [ ] Новая карточка синхронизируется с другим устройством.
- [ ] Сохраняется позиция просмотра.
- [ ] Сессия сохраняется после перезапуска приложения и телевизора.
- [ ] Выход и повторный вход работают.

Не добавляйте CUB credentials, токены или содержимое localStorage в Git и отчёты.
