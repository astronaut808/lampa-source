# Установка на Hisense VIDAA через VidaaEdge

VidaaEdge устанавливает отдельную PWA-запись с названием, иконкой и URL Lampa. Это не APK и не нативный бинарник.

## Перед началом

Запишите модель телевизора, версию VIDAA и прошивку. Возможности установки зависят от модели и firmware.

Убедитесь, что телевизор открывает:

```text
http://<IP-СЕРВЕРА>:8090
```

## Подготовка VidaaEdge

Размещайте VidaaEdge отдельно от Lampa:

```bash
git clone https://github.com/weinzii/vidaa-edge.git
cd vidaa-edge
npm install
npm start
```

По актуальной документации VidaaEdge это запускает API на порту `3000` и HTTPS-интерфейс на порту `443`.

## DNS

Создайте в AdGuard Home, Pi-hole или локальном DNS запись:

```text
vidaahub.com → IP сервера VidaaEdge
```

Желательно применять rewrite только к телевизору. Не подменяйте домены CUB.

## Установка

1. На телевизоре откройте браузер.
2. Перейдите на `https://vidaahub.com/`.
3. В установщике создайте приложение:

```text
App ID: astronaut-lampa
Name: Astronaut Lampa
App URL: http://<IP-СЕРВЕРА>:8090
```

4. Укажите URL подготовленных иконок, когда они будут добавлены.
5. Нажмите Install.
6. Полностью перезагрузите телевизор.
7. Найдите Astronaut Lampa в конце списка приложений.

VidaaEdge автоматически выбирает доступный на телевизоре метод установки. Если кнопка ничего не делает, необходимые Hisense API могут отсутствовать в прошивке.

После успешной установки проверьте запуск без DNS rewrite. Если приложение открывает прямой URL Lampa, подмену `vidaahub.com` можно отключить.

## Обязательная проверка

- запуск с домашнего экрана;
- пульт: стрелки, OK и Back;
- экранная клавиатура;
- сохранение localStorage после перезагрузки;
- вход CUB;
- установка плагина;
- воспроизведение и перемотка;
- обновление Lampa без переустановки PWA.

VidaaEdge — экспериментальный неофициальный инструмент. Используйте его только на собственном телевизоре и в доверенной LAN.
