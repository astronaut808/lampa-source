# Диагностика воспроизведения

Astronaut Lampa отправляет на локальный metrics-контейнер обезличенный отчёт о каждой попытке воспроизведения.

Отчёт содержит:

- этап, на котором завершилась попытка;
- время до запуска плеера, метаданных, `canplay` и `playing`;
- количество и длительность ожиданий;
- ошибки медиаплеера;
- тип потока и домен CDN/балансера;
- длительности и статусы запросов, выполненных через `Lampa.Reguest`.

Полные URL потоков, query-параметры, заголовки, cookies, названия фильмов и данные аккаунта не сохраняются.

Последняя попытка:

```bash
curl -s http://127.0.0.1:8090/metrics/playback
```

Последние 500 попыток:

```bash
curl -s http://127.0.0.1:8090/metrics/playback/history
```

Очистить историю воспроизведения:

```bash
curl -X DELETE http://127.0.0.1:8090/metrics/playback/history
```

Основные результаты:

- `timeout` в фазе `resolver` — источник или балансер не довёл запрос до запуска плеера за 30 секунд;
- `timeout` в фазе `player` — плеер создан, но событие `playing` не наступило за 30 секунд;
- `error` — медиаплеер сообщил ошибку;
- `playing` — воспроизведение началось;
- `closed` или `ended` — окончательное состояние после закрытия или завершения.

На iPad нативный HLS-плеер не раскрывает приложению все запросы отдельных сегментов. Поэтому отчёт может определить проблемный этап, но не всегда точную внутреннюю ошибку CDN.

Диагностика включена по умолчанию. Её можно полностью отключить без пересборки:

```env
LAMPA_PLAYBACK_METRICS_ENABLED=false
```
