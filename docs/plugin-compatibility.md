# Совместимость плагинов

Штатный loader плагинов не изменён.

| Плагин | URL | Загружается | UI | Источник | VIDAA | Примечание |
|---|---|---:|---:|---:|---:|---|
| Не проверен | — | — | — | — | — | Заполнить после реального теста |

Для каждого используемого плагина проверьте HTTP status, MIME type, CORS, работу пульта и воспроизведение.

```bash
curl -IL 'https://example.com/plugin.js'
curl -fsSL 'https://example.com/plugin.js' | head
```

Не добавляйте неизвестные плагины автоматически: код плагина исполняется с доступом к странице Lampa.
